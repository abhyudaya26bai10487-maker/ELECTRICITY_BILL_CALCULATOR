Electricity Bill Calculator

1. Project Overview

This is a simple Electricity Bill Calculator made in Python for the VITyarthi Build Your Own Project activity.

The idea is straightforward: the user enters a customer name, consumer ID, and the number of electricity units used. The program then calculates the bill using different unit slabs and shows a clear bill on the screen.

We kept the project simple on purpose because it is meant to show the Python concepts learned in the first year instead of making a complicated application.

2. Main Features

Takes customer details as input.

Accepts electricity units from the user.

Calculates the energy charge using slab-wise rates.

Adds a fixed charge.

Adds a small surcharge when the energy charge crosses the selected limit.

Displays the final bill.

Saves generated bills in a text file.

Handles common invalid inputs.

Keeps the program divided into small Python files.

4. Project Files

main.py - starts the program and connects the modules.

bill_calculator.py - performs the bill calculation.

input_handler.py - takes and validates user input.

tariff.py - stores tariff-related values.

bill_history.py - saves generated bills.

report.py - displays the final bill.

utils.py - contains small helper functions.

test_bill_calculator.py - contains basic calculation tests.

statement.md - project problem statement and scope.

design.md - design and diagrams.

requirements.txt - project setup information.

bill_history.txt - created automatically after the first bill is generated.

5. How to Run

Install Python 3 on the computer.

Keep all the .py files in the same folder.

Open the folder in a terminal or Python editor.

Run:

python main.py

Enter the requested customer details and units.

No external Python package is required.

6. How to Test

Run:

python test_bill_calculator.py

The test file checks some sample unit values and their expected calculations.

7. Tariff Used in This Student Project

Units

Rate

First 100 units

Rs. 3.00/unit

101-200 units

Rs. 4.50/unit

201-400 units

Rs. 6.50/unit

Above 400 units

Rs. 8.00/unit

A fixed charge of Rs. 50 is added. A 5% surcharge is added when the energy charge is more than Rs. 500.

These are project assumptions for demonstration and are not intended to represent an actual electricity board's current tariff.
