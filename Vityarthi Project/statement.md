Project Statement

Problem Statement

Electricity bills are normally calculated from the number of units consumed during a billing period. For a student learning Python, doing this calculation manually is a useful example of applying programming concepts to a small real-world problem.

The aim of this project is to make a basic Electricity Bill Calculator that accepts customer information and electricity consumption, calculates the bill according to predefined slabs, and displays the result in a simple format.

Scope

The project is limited to a console-based Python application. It does not connect to a real electricity provider and it does not make online payments.

The project covers:

Customer input

Unit consumption input

Slab-wise calculation

Fixed charge

Surcharge calculation

Bill display

Saving a simple local bill history

Target Users

The project is mainly intended for students and beginners who want to understand how Python can be used for a small practical calculation system.

It can also be used as a simple demonstration of how input, processing, output, functions, modules and file handling work together.

High-Level Features

Enter customer details.

Enter electricity units.

Calculate energy charges.

Add fixed charge and surcharge where applicable.

Display the final bill.

Save the bill in a local text file.

Expected Outcome

The user should receive a clear electricity bill on the screen with the units used, individual charges and final amount.
